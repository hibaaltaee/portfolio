# Hiba Altaee — Portfolio
React + Vite + Tailwind CSS

## Structure
- src/data/portfolio.js  ← Edit ALL your content here
- src/components/        ← One file per section
- src/hooks/useInView.js ← Scroll animations

## Commands
npm install && npm run dev   # dev server
npm run build                # → dist/

## Deploy to Netlify (Auto-deploy on push)
1. Push to GitHub
2. netlify.com → New site → Import from Git
3. Build: `npm run build` | Publish: `dist`

## Deploy to Netlify (Drag & Drop)
1. npm run build
2. Drag dist/ folder to netlify.com/drop
